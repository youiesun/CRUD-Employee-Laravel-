# CRUD Employee Laravel

This is a simple CRUD (Create, Read, Update, Delete) Employee management system built with Laravel.

## Features
- Add employee
- Edit employee
- Delete employee
- View employee list

## Tech Stack
- Laravel
- PHP
- MySQL
- Blade

## How to Run
1. Clone the repository
2. Run `composer install`
3. Copy `.env.example` to `.env`
4. Run `php artisan key:generate`
5. Configure database in `.env`
6. Run `php artisan migrate`
7. Run `php artisan serve`
